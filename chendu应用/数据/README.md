# 数据说明

V2.0 起，`chendu应用` **不再使用任何数据库**：PostgreSQL、Flyway 迁移、Flowable 工作流表、`workbench_user` 账号表与演示账号播种均已在本次精简中移除。

## 当前状态

| 项 | 值 |
| --- | --- |
| 数据库 | 无（未配置数据源，`spring.datasource` 已移除） |
| 迁移工具 | 无（`db/migration` 已删除） |
| 持久化数据 | 无；应用重启后状态全部丢失 |
| 缓存 | 无（Redis 依赖与缓存接口已删除） |
| 账号体系 | 无（Spring Security、JWT、`workbench_user` 已删除） |
| 建库脚本 | 无（`数据/初始化/` 已删除） |

## 历史数据处置

本次变更前，本机与共享实例中可能已存在以下对象，本次**未执行任何删除操作**：

| 对象 | 说明 | 处置建议 |
| --- | --- | --- |
| 本机 PostgreSQL 库 `ai_scaffold` | 旧版本业务表与 Flowable 表 | 保留即可；不再被本应用连接 |
| 共享实例库 `ai_scaffold_chendu` | 原计划的同机独立库，若已创建则不再使用 | 由数据库管理员确认后决定是否删除 |

数据库删除属于生产写操作，必须按规则第 6 节单独确认，不能随本版本发布顺带执行。

## 变更约定

- 后续如需恢复持久化能力，应作为独立任务提出，并同时补齐：数据源配置、版本化迁移、健康检查、测试与生产写入审批。
- 迁移文件一旦在共享环境执行过，不得修改；本次已删除的历史迁移可从 Git 历史（`20dcc4f` 之前）取回。
