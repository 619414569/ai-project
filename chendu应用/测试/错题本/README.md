# 错题本

本目录记录 `chendu应用` 的缺陷、命令错误、构建失败、部署失败和生产操作异常。

## 记录规范

1. 提报或修复前先按错误消息、接口、模块和环境检索已有记录，避免重复编号。
2. 同类问题复发时在原记录追加时间、环境、遗漏原因、影响、修复和防复发措施。
3. 新问题必须包含：编号、日期、严重度、状态、摘要、原始错误、根因、修复和可重复回归用例。
4. 没有回归用例或验证证据，不得标记为 `resolved`。
5. 发布门禁要求所有问题均为 `resolved`，并人工复核，不能只依赖脚本退出码。
