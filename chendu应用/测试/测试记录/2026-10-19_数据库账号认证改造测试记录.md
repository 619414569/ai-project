## 数据库结构变更说明（规则 7.2 / 7.3）

新增业务表 `public.workbench_user`，由 `backend/src/main/resources/db/migration/V2__create_workbench_user.sql` 创建。

| 项 | 说明 |
| --- | --- |
| 领域归属 | 认证与账号（`com.aiproject.scaffold.user`） |
| 表职责 | 保存可登录的账号、BCrypt 口令散列与授权角色，替代原先由配置项构造的演示账号 |
| 主键 | `username` |
| 外键 | 无（`V2` 未引入跨表引用） |
| 唯一约束 | `username` 主键即唯一约束 |
| 索引 | 无额外索引；当前仅按主键 `username` 查询 |
| 审计字段 | `created_at`、`updated_at`，均为 `TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP` |
| 清理策略 | 暂不自动清理；演示账号播种由 `APP_DEMO_DATA_ENABLED` 开关控制 |
| 兼容影响 | 登录接口签名与响应结构不变；原先仅存在于配置中的账号现需落库后才可登录 |

字段定义与业务用途备注：

| 字段 | 类型 | 约束 | 业务用途备注 |
| --- | --- | --- | --- |
| `username` | `VARCHAR(64)` | 主键 | 登录名，业务主键且全局唯一，登录请求提交的 `username` 与此列比对 |
| `password_hash` | `VARCHAR(100)` | `NOT NULL` | BCrypt 口令散列，只保存散列不保存明文，登录时由 `DaoAuthenticationProvider` 比对 |
| `roles` | `VARCHAR(255)` | `NOT NULL` | 账号拥有的角色清单，英文逗号分隔，例如 `ADMIN,USER`；读取时拆分并映射为 `ROLE_` 权限 |
| `password_change_required` | `BOOLEAN` | `NOT NULL DEFAULT TRUE` | 为 `true` 表示登录后需先修改口令；当前版本未提供改密接口，播种的演示账号显式置为 `false` |
| `active` | `BOOLEAN` | `NOT NULL DEFAULT TRUE` | 为 `false` 表示账号已停用，加载时映射为 `disabled` 并拒绝登录 |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT CURRENT_TIMESTAMP` | 账号首次写入时间，用于审计 |
| `updated_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT CURRENT_TIMESTAMP` | 账号信息最后更新时间，改密时同步刷新 |

## 自动化测试用例

### 新增：`backend/src/test/java/com/aiproject/scaffold/user/DatabaseUserDetailsServiceTest.java`

类型：Spring Boot 集成测试（`@SpringBootTest`，`webEnvironment = MOCK`，`@Transactional`）。

> 说明：这里使用 `MOCK` 而非 `NONE`，因为 `SecurityConfig#securityFilterChain` 依赖 `HttpSecurity`，只有模拟 Web 环境才会提供该 Bean；`MOCK` 不占用端口。所有用例在事务内执行，结束自动回滚，不残留临时账号。

| # | 用例 | 断言要点 | 结果 |
| --- | --- | --- | --- |
| 1 | `loadsPrimaryDemoUserFromDatabase` | 主演示账号从 `workbench_user` 加载成功，散列与配置口令匹配，账号启用 | 通过 |
| 2 | `loadsAdditionalDemoUserDcy` | `dcy` 可加载、散列与配置口令匹配、权限恰为 `ROLE_USER` | 通过 |
| 3 | `storesPasswordHashOnly` | 库中存的是 BCrypt 散列（`len=60`，前缀 `$2a$`），不等于明文口令 | 通过 |
| 4 | `rejectsUnknownUsername` | 不存在的用户名抛出 `UsernameNotFoundException` | 通过 |
| 5 | `disablesInactiveUser` | `active=false` 的账号 `isEnabled()` 为 `false`，角色仍正确解析 | 通过 |
| 6 | `parsesRolesFromCommaSeparatedColumn` | 角色字段 `" ADMIN , , USER "` 正确拆分为 `ROLE_ADMIN`、`ROLE_USER`，空项被忽略 | 通过 |
| 7 | `updatePasswordReplacesHashAndClearsFlag` | 改密后新散列匹配新口令、旧口令不再匹配，`password_change_required` 被清除 | 通过 |
| 8 | `updatePasswordRejectsUnknownUser` | 对不存在的账号改密抛出 `UsernameNotFoundException` | 通过 |
