## 1. 变更目标

按「简化、去掉杂乱依赖，只需要能运行」的要求，移除：

1. **Spring Security / JWT / RBAC / 数据库账号体系**（连带 `workbench_user`、演示账号播种、登录页）
2. **Redis 缓存**（连带缓存示例接口）
3. **PostgreSQL / Flyway / JDBC**（连带 `db/migration`、建库脚本）
4. **Flowable**（依赖数据库）
5. **RocketMQ**（连同配置一起移除：仅删配置会因占位符无值导致启动失败）

最终形态：一个连通性接口 + 健康检查 + OpenAPI，无任何外部中间件依赖。

## 4. 风险与待确认项

1. **无鉴权**：所有接口对能访问 `81` 端口的调用方开放，部署时必须用安全组/反向代理限制来源。
2. **无持久化**：应用重启即丢失状态；后续若需要数据能力必须作为独立任务重建。
3. **功能极简**：目前仅有连通性接口，业务接口需要重新开发。
4. **历史数据未清理**：本机库 `ai_scaffold`、共享实例库 `ai_scaffold_chendu`（若已创建）均未删除，属生产写操作，需单独确认。
5. **前端样式残留**：`styles/index.css` 中登录页、用户信息、待办、缓存等选择器已无引用，属无害死代码，本轮未清理。
6. **无跨域配置**：已移除 CORS，浏览器跨域直连会被拦截；前端经 Nginx 反代 `/api`，属同源访问，不受影响。
