# 工作台功能测试文档

## 1. 测试目标

验证工作台在脚手架技术栈上的功能、权限、数据持久化、构建和独立运行能力。只有所有 P0/P1 用例通过，且不存在未关闭的阻断或严重缺陷，才能判定验收通过。

## 2. 测试范围

- Spring Security JWT 登录、退出和持久化修改密码。
- 个人应用、其他成员共享应用、合作应用和合作人权限。
- 应用地址选填、补填、校验和跳转。
- 应用共享/独享、暂停/恢复和删除。
- 按用户展示和筛选提交日志。
- 前后端独立构建、Docker 镜像和 Compose 集成。
- 桌面端与移动端关键流程。

## 3. 测试环境

| 项目 | 要求 |
| --- | --- |
| Java | Temurin/OpenJDK 17 |
| Maven | 3.9+ |
| Node.js | 22+ |
| 数据库 | PostgreSQL 16，兼容 PolarDB-PG |
| 浏览器 | Chromium 最新稳定版 |
| 容器 | Docker Engine 24+、Compose v2 |
| 默认账号 | `admin` / `admin123` |

## 4. 验收规则

- P0、P1 用例必须全部通过。
- 自动化测试必须零失败、零跳过。
- 前后端生产构建必须成功。
- 未授权访问、越权修改和危险 URL 必须被拒绝。
- 测试结果必须记录实际输出；未执行项保持“未执行”或“阻塞”，不得记为通过。
