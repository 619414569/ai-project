# 中文路径下 Flowable 启动失败

## 原始报错

```text
Failed to start bean 'springProcessEngineConfiguration'
org.flowable.bpmn.exceptions.XMLException: src-resolve: 无法将名称 'extension' 解析为 element declaration 组件
```

## 根因

Windows 默认 JVM 编码下，Spring Boot 可执行 JAR 位于中文目录时，Flowable 嵌套 XSD 资源 URL 被错误编码。相同 JAR 在 ASCII 路径或显式启用 UTF-8 时可正常部署流程。

## 修复与防复发校验

- 后端 Maven JVM、独立 JAR 命令和容器入口统一指定 `-Dfile.encoding=UTF-8`。
- 发布前必须从包含中文字符的路径启动一次 JAR，并确认日志出现 `Started AiScaffoldApplication`。
