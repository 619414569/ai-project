# ai-project
> 仓库内所有用户和智能体必须先阅读并遵守 [`规则/rules.md`](./规则/rules.md)。规则文件只有经过用户明确确认后才允许修改。

1、本项目为小组内研发AI功能专用仓库
2、每个人负责各自的模块，每周至少一次更新，每周定时提交更新日志
3、可以多人组队开发同一个模块，也可以依赖于框架独立设计自己的功能模块
4、基础功能框架：
  a.框架底座
  b.登录模块（用户名 + 密码）
  c.日志模块
  d.工作台模块
5、每个人至少选一个市面上的中高级的智能体
6、前三个月可以进行工具类、统计类的应用开发，三个月后每个人必须进入Agent开发阶段
7、个人提交记录统一维护在[提交日志](./提交日志/README.md)目录

## 研发与交付规则

目录、脚手架、个人分支、生产数据审批、输入输出校验、测试、验收、版本、提交和发布门禁统一以 [`规则/rules.md`](./规则/rules.md) 为准，其他文档中的说明不得覆盖该文件。
