# AI 应用工作台 V1.1

发布日期：2026-10-14
更新人员：ZLS
更新类型：小版本

## 更新概述

加强登录信息安全，并将版本更新记录纳入工作台提交日志区域，支持按人员查询和在线预览 Markdown 更新说明。

## 新增功能

- 建立从 `V1.0` 开始的小版本和大版本递增规则。
- 每次版本更新使用独立 Markdown 文件记录，不覆盖历史记录。
- 提交日志区域增加版本更新日志列表，按文件名倒序展示。
- 支持按更新人员和关键词查询版本日志。
- 点击日志文件名可在工作台内在线预览 Markdown 内容。
- Docker 以只读方式向后端挂载更新日志目录。

## 调整内容

- 登录页账号和密码默认留空。
- 登录页及首次改密弹窗不再显示默认密码明文。
- 保留首次登录强制修改密码流程。

## 质量保障

- 后端校验日志索引和读取路径，拒绝路径穿越。
- 前端使用成熟 Markdown 解析器并在渲染前清理不安全 HTML。
- 新增版本序列、索引顺序、文件存在性、列表筛选和在线预览回归测试。
- 使用公网 `1888` 地址完成真实浏览器验收，人员查询、文件名倒序和 Markdown 页面内预览均通过。
- 未入索引文件、非法路径段和编码路径穿越载荷均被拒绝，无法读取日志目录外文件。
