# 浏览器验收混用登录用户与日志作者

## 原始问题

V1.1 公网页面验收登录成功并加载日志列表后返回：

```text
Error: Timed out waiting for author option
```

## 根因

脚本使用 `zls` 账号登录后，又用同一个变量查找版本日志作者选项。当前两份版本日志的作者是 `619414569`，人员筛选列表中不存在 `zls`，因此等待超时。登录身份和更新日志作者是两个不同的业务维度，不应共用测试参数。

## 修复

- 保留 `E2E_USERNAME` 仅用于登录。
- 新增独立的 `E2E_LOG_AUTHOR` 参数用于版本日志人员筛选，默认值为当前日志作者 `619414569`。
- 验收结果单独记录实际筛选的日志作者，不使用登录用户名代替。

## 防复发校验

- 浏览器验收使用非日志作者账号登录，再按日志作者筛选，验证两个身份维度相互独立。
- 筛选后断言日志行数和文件名顺序，再执行 Markdown 在线预览断言。
