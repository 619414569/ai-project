# 版本更新日志

本目录是工作台“提交日志 > 版本更新日志”的唯一数据源。更新日志按人员目录归档，并由 `index.json` 提供结构化索引。

## 版本规则

- 初始版本固定为 `V1.0`。
- 缺陷修复、兼容调整和向后兼容的功能增加属于小版本，版本小数位递增，例如 `V1.0` -> `V1.1`。
- 架构重构、不兼容变更或产品范围显著扩展属于大版本，整数位递增并将小数位重置为 `0`，例如 `V1.9` -> `V2.0`。
- 每次版本变化必须新增独立 Markdown 文件，不允许覆盖历史版本记录。
- 文件名格式为 `YYYY-MM-DD_V<major>.<minor>.md`，网页按文件名倒序展示。
- `index.json` 中的 `author` 使用 Git 提交人名称，便于网页按人员搜索。

## 校验

从应用目录执行：

```bash
node scripts/check-update-logs.mjs
```

校验内容包括版本起点、相邻版本递增规则、索引倒序、重复项和 Markdown 文件存在性。
