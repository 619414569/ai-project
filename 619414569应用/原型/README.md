本目录归档工作台 v1.0 的过程原型。实际应用源码位于[上一级应用目录](../README.md)。

## 原型文件

- [workbench-v1.0.html](./workbench-v1.0.html)：可离线打开的交互原型，不依赖后端服务。
- `workbench-v1.0.html?preview=workspace`：直接进入工作台审阅模式。
- `node validate-prototype.mjs`：校验原型脚本语法、页面区域、元素 ID 和关键需求文本。
- 原型登录账号：`chyong`，默认密码：`admin123`。

## v1.0 页面结构

用户登录后直接进入单页工作台，内容按以下顺序纵向排列：

1. 我的个人应用。
2. 按创建人分组的其他成员共享应用。
3. 合作应用。
4. 按用户筛选的提交日志。

登录页支持账号密码登录。默认密码为 `admin123`，首次登录后弹出修改密码对话框。应用创建时地址为选填项；存在地址时打开对应页面，不存在地址时提示补填。

个人应用和合作应用均支持创建、共享/独享、暂停/恢复、地址补填和删除。合作应用创建时必须选择至少一名合作人，只有创建人拥有管理权限。
