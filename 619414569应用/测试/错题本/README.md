# 错题本

错题本用于记录已经发生的缺陷、原始报错、根因、修复方式和自动回归用例。目标不是只关闭当前问题，而是让同类错误在提报和发布阶段被主动拦截。

## Bug 提报规则

1. 提报前先按错误信息、接口、页面和模块检索本目录，确认是否已有同类问题。
2. 新问题必须新增独立 Markdown 文件，保留原始状态码、错误消息、请求 ID 或关键日志。
3. 修复必须给出可重复执行的回归用例；没有回归用例不得将 `status` 改为 `resolved`。
4. 同类问题再次发生时，不新建重复条目；在原条目追加复发时间、环境和遗漏原因，并提高回归覆盖。

## 发布规则

1. 日常 CI 执行 `node 619414569应用/测试/check-error-notebook.mjs`，校验记录结构和编号。
2. 发布 `v*` 标签时执行 `node 619414569应用/测试/check-error-notebook.mjs --release`。
3. 发布门禁要求所有条目均为 `resolved`，且关联回归测试全部通过。
4. 发布负责人必须逐条核对本目录，不能只依赖脚本退出码。

## 记录字段

每条记录顶部必须包含：`id`、`date`、`severity`、`status`、`summary`、`regression`。`status` 只允许 `open` 或 `resolved`。
