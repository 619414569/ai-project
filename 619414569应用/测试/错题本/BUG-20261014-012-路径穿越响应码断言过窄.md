# 路径穿越响应码断言过窄

## 原始问题

公网日志读取安全验证对 `%2e%2e` 载荷执行断言时返回：

```text
Traversal expected 400/404, got 401
```

## 根因

包含编码父目录段的请求在进入 `UpdateLogController` 前被 Spring Security 防火墙拒绝，因此返回 401；测试只允许业务服务返回的 400 或 404，没有覆盖安全层提前拒绝这一合法结果。该请求没有进入索引查询或文件读取。

## 修复

- 将安全校验拆分为未知索引文件、非法路径段和安全层穿越载荷三类。
- 未入索引的合法文件名断言为 404。
- 保持控制器路由结构的 `..\\secret.md` 非法文件名断言为 400。
- 被安全防火墙提前拒绝的编码父目录段允许 401，并同时确认不能得到日志内容或 2xx 响应。

## 防复发校验

- 读取接口只允许索引中存在且通过安全字符校验的 Markdown 文件返回 200。
- 路径穿越回归同时覆盖业务校验层与安全防火墙层，所有载荷必须是 400、401 或 404，禁止任何 2xx。
- 状态码断言必须和实际拒绝请求的组件层级一致，不能把安全层拒绝误判为文件访问漏洞。
